# Security

### Propósito de este documento

Describe cómo reportar vulnerabilidades y qué queda fuera del alcance de seguridad de este repositorio.

## Reporting

Report security issues privately to the repository owner (`@Alexendros` on GitHub). Do not open public issues for undisclosed vulnerabilities.

## Scope

- This repo publishes design tokens, CSS variables, a minimal theme-boot and documentation. It does not handle authentication, payments or user data.
- No runtime secrets are required. See `.env.example`.

## Supported versions

Security fixes target the default branch (`main`) of `@soluciones-alexendros/ds`.
