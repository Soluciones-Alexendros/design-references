# ADR-0006 — Base del sitio (Starlight vs Astro plano)

- **Estado:** Proposed
- **Fecha:** 2026-11-10

## Contexto

Docs actuales: Astro plano en `apps/docs` (3 páginas). Default del prompt: Astro + Starlight.

## Decisión

Mantener Astro plano hasta Fase 5 (sitio). Starlight queda como opción a evaluar con evidencia de coste/migración; este ADR no cierra la elección.

## Alternativas

- Migrar a Starlight en Fase 1 — fuera de alcance.
- MDX custom sin Starlight — posible si Fase 5 lo justifica.

## Consecuencias

Fase 1 no toca la app de docs salvo punteros documentales.
